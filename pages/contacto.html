¿Cómo funciona?

El navegador comprueba que los campos estén completos y que el correo tenga un formato válido.

Este proyecto es estático : no tiene servidor, base de datos ni una dirección de envío configurada.

Etiquetas usadas

  • <form> agrupa los campos.
  • <label> identifica cada control.
  • <input> recibe textos y correo.
  • <textarea> recibe mensajes largos.
  • <button> activa la validación.
